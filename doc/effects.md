# 效果与依据

各项效果的做法、依据、实测和文献。文中的命令行参数也对应 Rust 版的同名滑块。[掏耳](#掏耳入耳--style-earclean)、`--front`、`--breath-reach` 和新版 KU100 实录预设使用 Rust 引擎。界面操作见[界面使用说明](app-usage.md#参数)。

## 默认效果：贴耳加强（D2）+ 忽远忽近

默认设置来自试听反馈（D 版"贴耳加强"效果最好），再按论文做了增强：

| 做法 | 依据 | 参数（默认值） |
|---|---|---|
| 嘴离耳朵约 1.7 cm，远耳再压低 32 dB，声音干、不加房间 | 真实 KU100 贴耳录音两耳差 31–38 dB；Shimokura 2022：越"近"、两耳越不相关，ASMR 越强 | `--dist`（0.105）`--isolation 32` `--room none` |
| 远耳 320 Hz 以下再压 12 dB、近耳低频加 5 dB | Brungart & Rabinowitz 1999：近处距离感主要靠低频两耳差；Honda 2020：128 Hz 两耳差的起伏与战栗感 r=0.93 | `--far-lf-cut 12` `--ear-warmth 5` `--warmth 6` |
| 25 cm 以内按"从每只耳朵看出去"的方向取耳廓响应（声学视差） | Romblom & Cook 2008；Spagnol 2017：视差在 20 cm 以内才明显 | 内置 |
| 贴耳位置略靠后（100°） | Kitagawa 2005：脑后近处的声音与触觉交互最强 | `--ear-angle 100` |
| 约 1/4 的换边改成"先退到约 0.5 m，再用 2–3 s 凑到耳边" | Serino 2015：逼近的声音进入身体周围 43–62 cm 后会增强触感；Honda 2020：移动比静止更易引发战栗 | `--approach 0.25` |
| 每只耳朵停 2.5 s，用 2.5 s 移到另一边（按说话时间算，停顿里不动），保留 20% 的响度随距离变化 | Spagnol 2017：响度是最强的距离线索；Honda 2020：慢转（18°/s）和快转（72°/s）效果相同 | `--hold-time 2.5` `--move-time 2.5` `--level-follow`（0.2） |
| 响度 −16 LUFS | 参考视频 −15.6 LUFS | `--lufs -16` |

### 忽远忽近（默认开启）

真人在耳边说话不会一动不动：贴着耳朵说一会儿，往后让一点，再凑回来。程序在左右穿梭的基础上让嘴到耳朵的距离一直在变（只改距离，方向不变），由两部分叠加。动起来本身就有用：Honda 2020 发现声源离耳 6 cm 移动时比静止更容易引起战栗感，与两耳差起伏的相关 r=0.93；Shimokura 2022 发现 ASMR 强度与"感觉有多近"相关 r=0.93。

| 做法 | 依据 | 参数（默认值） |
|---|---|---|
| 随机的"贴耳停留 → 慢慢往后让 → 稍停 → 慢慢凑回来"，循环往复。每段时长、退开深浅都随机：多数退到 3.5–7 cm，偶尔 7–16 cm，偶尔只让一点；贴近时至少停 2 s，一个来回约 4–7 s（说话时间），凑回来比退开慢 | KU100 实录（本项目测量 7 段）：两耳差起伏的标准差约 5.5 dB（约 ±1 倍距离），一个来回 2–23 s、中位 4–9 s。Lundbeck 2017：远近运动要约 2:1 的距离变化才听得出，所以退开幅度取 2–4 倍。逼近比远离更引人注意、听起来更快（Neuhoff 2016 综述；Ghazanfar 2002），所以凑回来比退开慢。脸周围的身体周围空间约 50–60 cm（Serino 2015），逼近越快范围越大（Noel 2018：52–77 cm），1–40 cm 全在其中。Koumura 等 2021：战栗感比声音滞后约 2 s，所以贴近时至少停 2 s | `--sway 1` `--sway-period 4` |
| 跟着说话音量：声音大的地方提前往后让（每响 6 dB 退远一倍，约提前 0.8 s），说完约 2.5 s 后才慢慢凑回来；轻声时更贴近 | 真实说话人离听者越远说得越大声、越近越轻：自然说话时每远一倍提高 1.3–2.2 dB（Pelegrín-García 等 2011）；响的字不会贴着耳朵炸出来，整体响度更均匀 | `--sway-follow 1` |
| 退开时耳边音量只保留物理衰减的 45%（说话人退开会不自觉地说大声一点）；房间声跟着说话人的音量走而不跟距离走，所以直达声 / 房间声之比按物理规律变化 | 自然说话人只补偿 1.3–2.2 dB/倍，耳边约每远一倍衰减 4 dB，即保留物理衰减的 65–75%（Pelegrín-García 等 2011）；ASMR 成品还经过压缩，KU100 实录只保留 40–56%（BV1X4ZyBREqr 56%、BV1XHBXBaEmt 40%、BV1hBsP6FE1g 44%）。这里取 45%，想更像自然说话可用 `--sway-level 0.7`。不能完全拉平：Arend 2016 发现把响度拉平后，听者分不出 0.25–1.5 m 的远近。说话人音量的变化加在混响送出之前，所以每靠近一倍，混响 −2 dB、直达声 +4 dB、直达 / 混响比 +6 dB（Kolarik 2016 综述；Zahorik 2002：直达 / 混响比的最小可察觉差 5–6 dB） | `--sway-level 0.45` |
| 远耳随距离自然"打开"：贴耳时几乎听不到，往后让时逐渐听得到，近耳的低频和临场感随之减弱 | Brungart & Rabinowitz 1999：近处侧方声源的距离感主要靠两耳差，500 Hz 两耳差从 1 m 处约 4 dB 增大到 0.125 m 处约 25 dB；Kan 等 2009：40 cm 以内的侧方声源，按距离变化函数渲染明显好于只改音量 | 内置 |
| 动作跟着说话：左右换耳、凑近 / 退开、微小晃动都只在说话时进行，停顿里几乎不动（速度 13%），下一句从上一句停下的位置接着说；声音大时动作幅度大（0.5–1.6 倍） | Hadar 等 1983（转引自 Tiede 等 2019）：说话时 89.9% 的时间头在动，不说话时只有 12.8%，动作幅度随音量峰值变化。原来换耳按固定时间表进行，落在停顿里时，下一句会"跳"到另一侧 | `--pause-motion 0.13`（1=旧版，一直在动） |

实测（病娇音声前 1 分钟）：
- 这段有 48% 的时间在说话。贴耳时离耳 1.3–6.3 cm（中位 2.6 cm），偶尔退到 20 cm 以上；每分钟换耳 6 次、往后让 7 次（说得越密，动得越勤）。
- 说话时距离变化速度中位 2.1 cm/s，90% 在 13 cm/s 以内。Honda 2020 发现 2 cm/s 和 8 cm/s 引起的战栗感相同；身体周围空间的逼近实验用 22–75 cm/s。
- 贴近停留中位 2.7 s（说话时间）。
- 最响 1% 的瞬时响度比中位数高 9.9 dB（不晃时 11.3 dB）。
- 停顿前后的位置差：距离中位变化 1.4 倍（旧版 2.0 倍），方向 90% 在 23° 以内（旧版 90°），不会"跳"到另一侧。

`--sway 0 --sway-follow 0` 关闭忽远忽近；再加 `--pause-motion 1 --updown 0 --breath 0 --puff 0 --concha 0 --soft-near 0 --mouth 0 --far-shadow 0`，结果与旧版默认逐样本相同。

### 上下（默认开启自动上下）

原来声源只在耳朵高度的水平面里移动，现在可以离开水平面。

| 做法 | 说明 | 参数 |
|---|---|---|
| 高度 | 嘴相对耳朵向上（正）/ 向下（负）偏多少度。以"耳朵"为支点转，嘴到耳朵的距离不变，所以音量不变，变的只是方向——贴耳时就是嘴绕着耳朵上下挪。声源在正前 / 正后方时支点是头中心，就是普通的仰角 | `--height 0` |
| 自动上下 | 嘴在耳朵上方 / 下方之间慢慢换位置：停一会儿 → 慢慢移过去 → 停一会儿 → 再移回来。停多久、每次到多高带随机，偶尔连续两次停在同一侧；按说话时钟走，停顿里不动 | `--updown 25`（度，0 = 关闭）`--updown-period 9` `--updown-random 0.6` |
| 从头顶绕 | 换耳时一定概率不从脸前 / 脑后绕，而是从这只耳朵升到头顶、再落到另一只耳朵 | `--over-top 0`（概率 0–1） |

怎么算的：

- 水平面的查找表不变。离开水平面时，两耳时间差、声级差和近场效应由"偏向哪只耳朵多少"（侧向角）决定（Morimoto 2001），所以取同一侧向角上水平面前 / 后两点的混合。
- 再给每只耳朵乘上"高度修正"：耳廓对来声方向的染色（Hebrank & Wright 1974：上下靠 4–16 kHz 的谱形）。修正取自同一个 KU100 在 1.5 m 的全球面实测（2702 个方向），做成 2 耳 × 37 个侧向角 × 36 个极角的 48 点滤波器。方向按"从这只耳朵看过去"算：近处的声源，耳朵看到的方向和头中心看到的不一样（声学视差，Brungart & Rabinowitz 1999），与水平面 0.25 m 以内的做法一致。
- 检验：用 1.5 m 得到的修正去预测 0.5 m 的全球面实测（没有参与建表），近耳的谱误差在 6–9 kHz 从 7.0 dB 降到 1.8 dB，9–13 kHz 从 5.2 dB 降到 1.5 dB。比 0.5 m 更近没有带高度的实测，贴耳位置的高度是模型外推。
- 两耳时间差不另外修正：同一侧向角上，实测时差随高度的偏移中位只有 11–14 µs。

实测效果（贴左耳，近耳各频段相对"与耳朵齐平"的变化）：

| 高度 | 6.3 kHz | 8 kHz | 10 kHz | 12.5 kHz | 4 kHz 以下 | 总音量 |
|---|---|---|---|---|---|---|
| 向上 40° | +1 dB | +7 dB | −6 dB | −12 dB | 3 dB 以内 | −0.3 dB |
| 向下 40° | −8 dB | +4 dB | −3 dB | −9 dB | 1 dB 以内 | +0.2 dB |

也就是耳廓造成的"缺口"随高度上移 / 下移，嗓音的主体不变。

上下是三个方向里最弱的：只靠 5 kHz 以上的高频，而且 KU100 的耳廓不是听的人自己的耳廓——非个人化 HRTF 下，上下和前后的判断误差明显增大（Wenzel 等 1993）。气声、轻语的高频多，上下会比低沉的嗓音清楚。

`--height 0 --updown 0 --over-top 0` 时结果与加入上下功能之前逐样本相同。

### 贴耳气声与耳甲共鸣（默认开启）

嘴贴近耳朵时，直达声中的轻微送气得到增强，同时加入由原声导出的低频气流和耳甲腔共鸣。贴耳加强风格下三者都随贴耳程度渐入。Rust 版另有「近处气声范围」，可以把一部分气声增强延伸到身前，气流和耳甲共鸣仍随贴耳程度变化。

| 做法 | 依据 | 参数（默认值） |
|---|---|---|
| 气声增强：2.5 kHz 以上是"气声带"。只把轻的部分提上来（频带内向上压缩）：比响的齿音低 16 dB 以上的送气声 / 气息 / 轻辅音最多提 6 dB，接近齿音电平的不提，低到底噪附近的也不提 | Klatt & Klatt 1990：气声感最主要的线索是 F3 以上取代谐波的送气噪声，而不是频谱倾斜；Hillenbrand 1994：只调频谱倾斜几乎得不到气声感。KU100 贴耳实录（下表）里气声段和有声段一样响，普通配音里气声段低 12–18 dB | `--breath 6`（dB，0 = 关闭） |
| 气流扑耳：送气时气流扑到贴着的那只耳朵上，形成 50–130 Hz 的压力脉冲。取嗓音自己气声带功率的低频起伏（除以功率的平方根），送气越强脉冲越强，爆破音开头最明显；幅度跟人声电平走，与音色明暗无关 | 喷麦声的能量在 200 Hz 以下、约 100 Hz 最强，持续 20–100 ms；KU100 贴耳实录的近耳 70–150 Hz 是每分钟约 170–200 次、中位 40 ms 的突发，并且只在贴着的那只耳朵里（下表）；Terashima 2024：40 / 80 Hz 的包络越强，刺痛感越强；Tajadura-Jiménez 2009：近处的声音会改变耳垂的触觉 | `--puff 1`（0 = 关闭） |
| 耳甲共鸣：贴耳时近耳 4.3 kHz 加一个约 0.8 倍频程宽的峰 | Shaw 1979：耳甲腔的深度共振在 4.3 kHz，各个方向来的声音都能激发。8 段 KU100 贴耳实录的近耳都有 4.3–4.6 kHz 的峰（+1…+3 dB）；而本程序在默认贴耳位置（100°、离耳 1.7 cm）用 25 cm 的实测数据外推，近耳 3.6–4.5 kHz 反而凹下去 8–13 dB | `--concha 4`（dB，0 = 关闭） |

"头壳共鸣"：没有找到 KU100 头壳本身有共振的证据（Bernschütz 2013：400 Hz 以下耳廓和头的形状几乎不起作用）。KU100 录音里共有的音色特征是耳甲共鸣（4.3–4.6 kHz 峰）、7–8 kHz 的耳廓谷、10–11.5 kHz 的峰和 1–2 kHz 的小起伏；后几样已经在实测 HRIR 里，缺的是贴耳时的耳甲峰，所以补的是它。听起来"在脑袋里嗡"的那部分，实录里主要是气流打在耳朵上的低频，对应上面的气流扑耳。

三段 KU100 贴耳实录（B 站，各 19–30 分钟）与本程序输出的对比（近耳，病娇音声前 1 分钟）：

| | KU100 实录 | 旧默认 | 新默认 | `--breath 10 --puff 2 --concha 6` |
|---|---|---|---|---|
| 有声帧占说话时间 | 5–17%（基本是耳语） | 约 70% | 同左 | 同左 |
| 气声段比有声段低多少（0.2–8 kHz） | 0…5 dB | 17 dB | 17 dB | 17 dB |
| 贴耳时 5–12 kHz 相对 0.2–2 kHz | 两段 −17…−20 dB，一段很暗的 −30…−34 dB | −19.9 dB | −15.5 dB | −11.0 dB |
| 近耳 4 kHz 相对 1 kHz（有声帧） | 两段 −7…−9 dB，一段很暗的 −18 dB | −11.6 dB | −7.4 dB | −4.0 dB |
| 贴耳时近耳 30–70 Hz 相对 0.5–8 kHz | −2…+15 dB | −32 dB | −15 dB | −11 dB |
| 低频突发：每分钟次数，中位时长 | 170–200 次，40 ms | — | 约 220 次，40 ms | 约 210 次，60 ms |

实录是耳语，普通配音是有声的嗓音，这个差别程序不去改（把嗓音改成耳语的做法试过，听起来不自然，已删除）；气流脉冲也比实录轻得多，想更明显可以调大 `--puff`。输入有底噪时气声增强会把贴耳时的高频底噪一起提高，先降噪。

**用数值仿真校验贴耳外推**：Salvador 等 2018 用边界元法（BEM）算了一个真人头模在离头中心 0.10–1.5 m、每 1 cm 一档的 HRTF（水平圈，每 1°）。在这套数据上照本程序的做法——由 0.25 m 的数据按"声学视差 + 球头模型"外推到更近——再和它自己的近距真值比（近耳，方位 55–125°，2–16 kHz，1/6 倍频程，去掉整体电平差）：

| 离耳 | 谱形均方根误差：视差 + 球头（本程序） | 不用视差 | 4–5 kHz 的平均偏差（方位 85–115°） | `--concha 4` 在同样离耳距离给的增益 |
|---|---|---|---|---|
| 13.8 cm | 0.5 dB | 0.7 dB | −0.5 dB | 0 dB |
| 7.8 cm | 1.9 dB | 2.5 dB | −1.7 dB | +1.2 dB |
| 5.8 cm | 2.8 dB | 3.6 dB | −2.3 dB | +1.9 dB |
| 4.8 cm | 3.4 dB | 4.4 dB | −2.7 dB | +2.3 dB |
| 3.8 cm | 3.9 dB | 5.3 dB | −2.8 dB | +2.6 dB |

- 视差取"从耳朵看出去"的方向（强度 1.0）就在最优附近：减弱视差误差变大，加强到 1.15 倍只再好 0.15 dB。
- 外推系统性少掉的正是 4–5 kHz 的耳甲共鸣，越近少得越多；`--concha 4` 补的量与它相差 0.2–0.6 dB，所以默认值不动。
- 剩下的误差主要是 7–10 kHz 耳廓谷的位置随距离移动，这是每个人耳廓各自的细节，换一个头不能照搬，没有去改。
- 远耳：贴耳时外推出来的高频偏亮（离耳 3.8 cm 时 9–10 kHz 高 8–9 dB）。默认风格远耳已另外压低 32 dB，不受影响；`--style ku100` 的远耳高频会比真实的略亮。
- 没有校验到的：离耳 3.8 cm 以内（数据最近到这里，默认贴耳是 1.7 cm）、上下方向、KU100 自己的耳廓（这是另一个头）。

### 贴耳轻声、嘴的大小、远耳高频遮挡（默认开启）

近场文献调研和 BEM 校验里能直接落到参数上的三项，都随贴耳程度渐入，离开耳边时为 0；都只是均衡 / 取样方式的变化，不加任何声音。

| 做法 | 依据 | 参数（默认值） |
|---|---|---|
| 贴耳轻声：凑到耳边时把嗓音均衡成"放轻声音"（和 `--soft-voice` 同一条 ANSI S3.5 说话力度曲线，但只在贴耳时），退开时恢复。默认 0.5：贴耳时 1–2.5 kHz 约 −1.3 dB、低频约 +1.3 dB | 说话力度是语音最主要的距离线索，越轻听起来越近，耳语第一次听就被判为最近（Brungart & Scott 2001；Philbeck & Mershon 2002）；人离听者越近说得越轻（Pelegrín-García 等 2011）。原来只模拟了"凑近时音量放轻"，没有模拟音色跟着变 | `--soft-near 0.5`（0 = 关闭） |
| 嘴的大小：嘴是约 2 cm 宽的开口而不是一个点。沿嘴宽方向取 5 个点，把各点的 HRIR 加权相加。贴耳时开口从耳朵看过去张角很大（离耳 1.7 cm、宽 2 cm 约 ±30°），点声源才有的又窄又深的耳廓谷变浅；离头中心 20 cm 以外与点声源没有差别 | ITU-T P.51：人工嘴的唇环直径 25 mm，声音不是从一个点出来的；Halkosaari & Vaalgamaa 2004：真人等效口半径约 0.5 cm，人工嘴 1.5 cm。实测：默认贴耳位置（100°、离耳 1.7 cm）近耳 3.6–4.5 kHz 的谷从 −12.7 dB 变成 −10.6 dB（宽 4 cm 时 −7.2 dB），其他位置变化在 1 dB 以内，是个很轻的修正 | `--mouth 2`（cm，0 = 点声源） |
| 远耳高频遮挡：贴耳时远耳 6 kHz 以上再压低，默认最多 5 dB（5 kHz −2 dB、8 kHz −3 dB、12 kHz −3.9 dB） | 上一节的 BEM 校验：球头模型低估了近处声源在远耳的高频头影，离耳 3.8 cm 时远耳 6 kHz 以上偏亮 2–9 dB；Brungart & Rabinowitz 1999：声源越近，远耳的头影越深。默认风格远耳已压低 32 dB，基本听不出；`--style ku100` 的远耳会更接近真实 | `--far-shadow 5`（dB，0 = 关闭） |

`--soft-near 0 --mouth 0 --far-shadow 0` 时结果与加入这三项之前逐样本相同。

调研里没有做成选项的：颅骨共振 / 骨导 / 次低频压力感（耳机的气导声做不出来）、为了亲近感加房间声（Lieberman 等 2022：加空间混响反而降低亲近感，所以默认仍然不加房间）、把耳廓谷按 BEM 结果移动（那是另一个人耳廓的细节，不能照搬）。

文献：Philbeck & Mershon 2002 JASA（[摘要](https://ro.uow.edu.au/sspapers/654/)）；[ITU-T P.51](https://www.itu.int/rec/T-REC-P.51)；Halkosaari & Vaalgamaa 2004（[ETSI 研讨会](https://portal.etsi.org/stq/workshop2004/presentations2004/060-directivity%20of%20human%20and%20artificial%20mouth%20-%20wsq%20workshop%200604.pdf)）；Lieberman 等 2022（[A voice inside my head](https://julianaschroeder.com/s/A-voice-inside-my-head-The-psychological-and-behavioral-consequences-of-auditory-technologies.pdf)）。

### 耳廓选择（默认 KU100）

把 KU100 的耳廓换成真人的：`--pinna A` … `--pinna G`（`--pinna list` 列出，默认 `ku100`）。

- **换的是什么**：近场的距离、两耳差、时延都保留 KU100 的实测数据，整体音色也仍是 KU100 的；换掉的只是 1.5 kHz 以上"随方向变化"的耳廓峰谷。做法是给每只耳朵的 HRIR 再卷上一个 64 点的修正滤波器 = 真人的方向传递函数 ÷ 本程序 KU100 渲染结果的方向传递函数（方向传递函数 = 某方向的响应 ÷ 所有方向的平均）。方向按"从这只耳朵看向声源"算，所以贴耳时与近场的声学视差一致；耳朵背对声源（在头影里）时不换。
- **数据**：HUTUBS 真人 HRTF 库（TU Berlin，96 个编号，实测 440 个方向，1.47 m），去掉 2 次人工头测量和 1 次重复测量后是 93 个真人。
- **为什么是 7 只**：每个人的耳廓不同，别人的耳廓不一定比 KU100 好——KU100 本来就是按平均人耳做的。有用的是能挑到像自己的那只：Katz & Parseihian 2012 让 45 人给 46 套 HRTF 打分，一小组就能让每个人都找到合适的，而且用自己评分最高的那套定位更准。这里把 93 个真人的修正曲线做聚类，取 7 个类的中心（按频谱聚类，不是按听感评分）：

| 名字 | HUTUBS 编号 | 这一类有多少人 | 与 KU100 相差（3–12.5 kHz 均方根） |
|---|---|---|---|
| A | pp40 | 46 | 3.5 dB |
| B | pp26 | 22 | 4.0 dB |
| C | pp76 | 12 | 3.5 dB |
| D | pp46 | 6 | 3.9 dB |
| E | pp54 | 5 | 4.7 dB |
| F | pp83 | 1 | 5.2 dB |
| G | pp74 | 1 | 4.4 dB |

- **怎么挑**：自己听时，用 `--mode orbit`（绕头转圈）各渲染一段，选前后最分得清、声音最不"贴在脑袋里"的那只。给别人听的成品建议仍用 `ku100`：听众的耳朵各不相同，没有哪只真人耳朵对所有人都更好。
- **实测**：贴耳位置近耳 2 kHz 以下不变，3–16 kHz 各频带变化 ±2–7 dB，每只耳朵各不一样；远耳不变。64 点滤波器与目标曲线相差均方根 0.11 dB。
- **要知道的局限**：
  - 93 个真人两两之间的差（中位 2.9 dB）比他们与 KU100 的差（中位 3.8 dB）小，说明修正里也带着两个实验室测量方式的差别，不全是耳廓的差别。
  - 选 7 只后每个人到最像那只的距离是中位 2.3 dB，只比随便两个人之间略好；F、G 是各自成一类的"特别的耳朵"。
  - 真人数据是 1.47 m 测的，贴耳时按从耳朵看的方向取用，没有近距离的验证。

`--pinna ku100`（默认）时结果与加入这一项之前逐样本相同。滤波表在 `data/pinna_hutubs.npz`（Rust 版在 `auto-asmr/assets/pinna.bin`），随仓库 / 程序分发，运行时不需要原始数据集；重新生成用 `auto-asmr/tools/build_pinna.py`。

### KU100 实录风格 `--style ku100`

#### 固定原声底噪

**两支麦克风的对照**

在同一台电脑上分别采集两路 Senary 输入，各 8 秒。阵列平均为 −31.5 dBFS，约 95% 的能量落在 100–300 Hz，最强谱线在 239–240 Hz。默认麦克风的 100 ms 分段电平中位数为 −72.7 dBFS，主要有 50 Hz 和 100 Hz 的嗡声。

把每份录音分别送进修改前后的实时引擎，均开启「KU100 实录」和「固定原声底噪」，手动把声源放在左耳侧，距头中心 11.5 cm。表中数字是指定时间窗内全频段左耳相对右耳的电平差。底声越接近 0 dB，表示它越少被带向左耳。

| 麦克风与时间窗 | 修改前 | 修改后 |
|---|---:|---:|
| 阵列，开头 0–0.25 秒 | +27.0 dB | +3.6 dB |
| 阵列，1–2 秒 | +26.2 dB | +1.2 dB |
| 阵列，4–8 秒 | +26.0 dB | +1.9 dB |
| 默认麦克风，4–8 秒 | +25.5 dB | +1.4 dB |

将声源改到右耳侧，阵列在最后 4 秒的电平差由 −25.4 dB 变为 −1.8 dB。默认麦克风接通时有一个例外，0.25–0.5 秒的输入电平达到 −58.4 dBFS，这个短促声音在两版中都跟随声源，向左约 27 dB。

另从第 2 秒起向阵列录音叠加已知波形的变调合成音节，用移动支路与干净音节的波形差计算误差。音节与背景等均方根电平时，目标信号对误差的比值由 0.4 dB 升至 6.5 dB，音节本身约衰减 2.4 dB。音节比背景高 6 dB 时，该比值由 6.4 dB 升至 9.9 dB，音节约衰减 0.8 dB。这项检查使用合成前景，耳语的主观听感还需要真人录音验证。

**单个频带怎样分配**

旧算法遇到高频气声时会把整帧送往移动声源，持续的高频设备嘶声也可能一直跟着嘴走。当前算法在低频按单个 FFT 频点观察嗡声。开场约 0.21 秒使用整帧谱形辅助初始化底噪，此后分别比较各带的短时功率、平滑功率和底噪估计。低频带可以继续固定，同时让突然出现的辅音进入移动支路。多个频带一起渐强时，用已建立底噪的各带功率比的下四分位估计共同增幅，单独几条新出现的谐波很难抬高其余频带的底噪。音高和底声长时间重合时，部分人声仍可能被分入固定支路。

**早期版本的开场渐入对照**

原先的估计器等待足够多的频带最小值。对《还是把哥哥关起来吧》的 AAC，开头约 0.235 秒后先出现极弱的编码前导，约 0.26 秒处底声渐入。在 0.4–0.8 秒，原录音两耳只差约 0.7 dB，上版开启固定底噪仍把绝大部分底声送到移动声源，输出向左偏 26.4 dB。此前以整段较静窗口的中位数判断，漏掉了这个开场问题。

此前针对开场渐入的改动从有信号的首批频谱帧开始估计，结合谱线集中度、频带间的功率分布和能量上升速度保护元音和突发气息。下表记录当时两个版本的结果。

对照采用同一首 30 秒 AAC 的右声道、种子 1，两版响度相差 0.001 LU。格内数字为 80 Hz–12 kHz 左右电平差，正值表示左耳更响。实时复测用同一解码器得到的浮点右声道，避免先转 16 位时抹掉极弱前导。

| 位置 | 加入开场估计前 | 加入开场估计后 |
|---|---:|---:|
| 0.26–0.46 秒，最先听见的底声 | +26.46 dB | 约 0 dB |
| 这 200 ms 内，逐个 10 ms 窗口的最大绝对差 | 29.13 dB | 0.10 dB |
| 4.4–4.8 秒，第一句明确的有声语音 | +21.6 dB | +21.6 dB |

从 0.2 秒到 2 秒分窗测量，文件版底声的绝对差均在 0.2 dB 内，无预读实时版在 0.1 dB 内。2.9–3.2 秒有一段短促的原声，在新版仍向左约 13 dB；这一段不能从单声道可靠判定是环境细响还是说话人的动作。检验时按瞬态单列。

**实时分离与开场噪声估计的依据**

- Li、Niu 与 Yang 在风扇噪声语音增强研究中分别处理稳定底噪和突变的谐波。作者摘要给出定性结论。本机阵列的主峰在 8 秒内保持在 239–240 Hz，因此本次实测覆盖的是稳定低鸣。回归测试另用缓慢变频、逐渐变响的谐波检查跟踪能力。[Li 等，2018（摘要）](https://doi.org/10.1145/3220162.3220164)
- FitzGerald 利用谱线跨帧的持续性分离音乐中的谐波和打击声。作者在两段音乐混音上比较硬、软掩模，软掩模的伪影较少，代价是两路之间有更多串音。这种取舍也出现在保留底声原始相位的分离器里，因此这里用麦克风底噪叠加已知音节，单独测前景损失。[FitzGerald，2010，第 3–4 页（全文）](https://www.dafx.de/paper-archive/2010/DAFx10/DerryFitzGerald_DAFx10_P15.pdf)
- Martin 用平滑频带功率的最小统计量估计噪声。Cohen 的 IMCRA 随频带中的语音存在情况调节噪声更新。两者都需要足够的观测。文件以数字静音开始时，静音里的零功率不足以描述之后的房间声。[Martin，2001](https://doi.org/10.1109/89.928915) · [Cohen，2003](https://doi.org/10.1109/TSA.2003.811544)
- Gerkmann 与 Hendriks 用软语音存在概率减少噪声功率估计的跟踪滞后。这支持在每帧、每个频带上连续分配前景和背景。本文程序的窗长、启动条件和权重是针对本引擎验证的工程选择。[Gerkmann 与 Hendriks，2012](https://doi.org/10.1109/TASL.2011.2180896)
- Sun、Yen 与 Alves 记录了两种相反的误判。噪声突然变响时，旧估计会把增大的能量当成语音，迟迟跟不上新底噪。持续元音超过短窗口时，窗口最低值又会把人声写进底噪。论文用频带组的局部最小值校正第一种误差，检测到连续浊音时暂停向最小值队列写入。作者指出低信噪比会降低谐波判断的可靠性。本机麦克风阵列录到的底声也有约 240 Hz 的稳定谱峰，因此测试分别检查持续嗡声和移动的人声。[Sun 等，2010，第 3–5 节（全文）](https://www.isca-archive.org/interspeech_2010/sun10d_interspeech.pdf)
- Triki 把每个频点连续几帧的协方差最小特征值排序。样本数接近矩阵维数时，直接取最小值容易受偶然低值影响，取较低顺位能减小误差。本项目在同一帧的不同频带间估计共同增幅，让少数新出现的人声谐波对整体底噪的影响较小。两种方法排序的对象不同，频带功率比的下四分位数是本项目的工程取值。[Triki，2011，第 3–4 节（全文）](https://www.isca-archive.org/interspeech_2011/triki11_interspeech.pdf)
- Chinaev 与 Haeb-Umbach 根据每个频点的非平稳程度调节最低统计之前的平滑速度，在 13 种噪声上用已知噪声谱核对跟踪误差。误差下降后，客观语音可懂度指标 STOI 的增幅仍较小。本项目用两项独立测量检查这一取舍：底噪有多少留在移动声源里，以及混入已知人声后，该支路保留了多少人声振幅。[Chinaev 与 Haeb-Umbach，2015，第 3–4 节（全文）](https://www.isca-archive.org/interspeech_2015/chinaev15_interspeech.pdf)
- Valin 的 RNNoise 将实时频带增益估计与音高滤波结合，目标是从带噪语音获得较干净的人声。ASMR 想保留录音底声，也想留下弱气声。耳语里无明显基频的辅音仍含有语音线索，直接把降噪器移除的声音全部当作房间声，会把一部分应随嘴移动的成分也移走。[Valin，2018](https://doi.org/10.1109/MMSP.2018.8547084) · [Jovičić 与 Šarić，2008](https://doi.org/10.1016/j.jvoice.2006.08.012)
- Marquardt 等研究双耳降噪中背景噪声的耳间相干性。对本项目的启发是分别核查背景和目标语音的空间线索。该论文使用双耳输入；这里从单声道估计背景并合成固定声场，验收时分别测量开场背景和第一句人声的两耳电平差。[Marquardt 等，2015](https://doi.org/10.1109/ICASSP.2015.7178050)
- Hu 与 Loizou 在四种噪声、两档信噪比下比较八种单麦克风增强算法。大多数条件下可懂度没有显著提高，音质和可懂度评分最高的算法也不同。这里把底声是否固定、弱辅音是否保留和有声起音的位置分别验证。[语音可懂度对照实验](https://doi.org/10.1121/1.2766778) · [RNNoise 作者的技术文章和试听](https://jmvalin.ca/demo/rnnoise/)

「固定原声底噪」在 KU100 实录预设中默认开启。以单声道输入为起点，从短时频谱估计持续存在的底声，保留其原始波形的相位。其余信号由对齐后的原声减去底声得到，两路相加可以还原输入。人声和短促气息照常进入移动的 KU100 直达声和房间反射。底声走一条固定的双耳路径，每耳幅频响应平直，低频基本同相，中高频有固定的相位差。两路在回放补偿前汇合，再一起经过输出响度和峰值处理。

分离器在 48 kHz 下使用 512 点短时傅里叶变换，128 样本一跳，跟踪各频带的低能量包络。持续的宽带底声可以更新噪声估计，突然出现的音节或呼吸优先留给移动声源。固定路绕过嘴的位置、距离增益和近耳均衡。输入门限和可选的 RNNoise 在分离前生效，因此开大降噪会减少可保留的房间底声。输入经过选声道或下混，固定声场是由该输入估计的；风扇或人声原本位于录音室的哪个位置，无法从单声道恢复。

实时模式增加 512 样本（约 10.7 ms）算法延迟，开关切换有约 20 ms 渐变；文件转换自动补偿这段延迟。分离器需要观察一段声音才能识别新的噪声底，长时间持续、和底噪频谱相近的耳语可能有一部分留在固定声场。旧配置缺少这项时沿用关闭状态，重新点「KU100 实录」可应用当前预设。

在同一段稳定白噪和合成人声上，把声源分别置于左、右耳边，以 250 Hz–8 kHz 测试。底噪的左右声级差从 +28.35 / −28.05 dB 降到 −0.04 / −0.03 dB；人声从 +25.00 / −24.52 dB 变为 +25.03 / −24.56 dB。正值表示左耳更响。

上一版《还是把哥哥关起来吧》前 30 秒的开关对照采用同一右声道和种子，两版均为 −16.46 LUFS。按原声每 50 ms 的 80 Hz–12 kHz 能量取较静的四分之一，剔除低于片段峰值 75 dB 的帧，再要求前后各 150 ms 都满足条件。所得 22 个安静窗口中，输出的两耳电平差绝对值中位数从 7.25 dB 降至 0.68 dB；原声距峰值 32 dB 以内的 202 个较响窗口，开关两版均为 6.96 dB。安静窗口可能含有尾音，不能视作纯底噪标签。

#### 轻呼吸与强辅音（当前 Rust 预设）

KU100 实录风格现在把「气声增强」从 10 调到 **12 dB**，「强辅音柔化」设为 **4 dB**。其余设置沿用上一轮的整轨标定。前者帮助听清句子里的轻微送气，后者控制耳边突出的个别辅音。可分别调节两者。

| 同一批较轻窗口，9–14 kHz | +0.90 dB |
| 较强、高频突出的 29 个窗口，4–6.3 kHz | −1.98 dB |

#### 早期标定

第一版用两段五月织姬的轻语实录（B 站 BV1X4ZyBREqr、BV1XHBXBaEmt）。第二版加入三位录制者各 19–30 分钟的实录，据此调整走位和音色。下表记录前两版的结果，统计前按频段扣除了实录的底噪。Python 版沿用第一版的走位，见[两版的关系](python-vs-rust.md)。

与默认的贴耳加强相比，没变的四项：远耳不额外压低（`--isolation 0`）、远耳低频不额外压（`--far-lf-cut 0`）、KU100 实测真实房间（`--room real`）、KU100 原机音色（`--headphone native`）。重新标定后改的：

| 做法 | 依据 | 参数 |
|---|---|---|
| 走位从"左右耳来回穿梭"换成随机走位：停在耳边、侧前、侧后或正面，约三分之一的停留在正面，停多久也不固定 | 三段实录里两只耳朵差不多（两耳差 < 6 dB）的时间占 30–32%，每一侧连续停留的时间从不到 1 秒到十几秒都有；旧版只有 9–10%，而且每侧都是约 4 秒，像节拍器。Honda 2020：两耳差的起伏越大战栗感越强（r = 0.93），但愉悦度越低（r = −0.76）——一直偏在一侧、来回切换更刺激，却不更舒服。正面不能占太多：没有头部追踪时正前方的声像最容易贴回脑袋里，侧方的声源外化得更好（Best 等 2020 综述） | `--mode random` `--front 0.35` `--hold-time 3` `--move-time 2.5` `--randomness 0.5` |
| 贴耳时更近（离耳约 2–4 cm，原来 6 cm） | 三段实录的两耳差 p90 是 28–41 dB（旧版 20 dB）：录制者有时贴得很近。中位数相近（实录 12.7–15.2 dB），所以是"偶尔很近"，不是一直很近 | `--dist 0.11` |
| 贴耳与正面之间的响度差收小 | 实录里说话响度的 p90 只比中位高 8–11 dB；随机走位按原来的 `--level-follow 0.5` 是 +15 dB，贴耳的那几句会突然变响 | `--level-follow 0.2` |
| 贴耳时气流扑耳更明显 | 实录贴耳时近耳 30–70 Hz 比 0.5–2 kHz 高 7.5–21 dB，旧版低 15–20 dB。这里只补到低 5–12 dB：再大的话低频脉冲的峰值会迫使限制器把整段压低（实录的响度只有 −20…−30 LUFS，峰值却已经到 0 dBFS） | `--puff 1.5` |
| 齿音和 5 kHz 附近收一点 | 实录里最响的齿音帧，5–12 kHz 比 0.5–2 kHz 高 9–20 dB（p99），旧版高 22–28 dB：普通配音的齿音比轻语实录刺。轻语本来就齿音重（Jovičić & Šarić 2008：耳语里浊辅音最多弱 25 dB，清辅音最多只弱 3.5 dB）；锐度越高愉悦度越低（Honda 2020，r = −0.76）；最让人不舒服的频段是 2.5–5.5 kHz（Kumar 等 2008）；问到 ASMR 视频"看了没感觉"的原因，16.5% 的回答提到声音刺耳（Barratt 等 2017） | `--deess 5` `--dark 2` |

没有动的：房间声的大小。用实录里的口腔音（瞬态）估计：瞬态之后 10–300 ms 的能量停在峰值以下 20–27 dB（中位），各个时间窗几乎一样、不随时间衰减——是底噪，看不出房间的尾巴，录音的房间很干；本程序的输出在同一口径下 10–80 ms 是 −23…−28 dB 并继续衰减，房间声已经不比实录少。房间声加多了外化会好一点，但亲近感下降（Lieberman 等 2022；有用的只是前 80 ms 的反射，Best 等 2020；真实教室里离头 15 cm 的侧方声源，近耳前 80 ms 的能量比之后的混响高 39 dB，远耳只高 11 dB，Shinn-Cunningham 等 2005）。实录里比说话低 25–40 dB 的底噪 / 房间底噪本程序不合成（见下面"真实感"一节）。

|---|---|---|---|

| 两只耳朵差不多（< 6 dB）的时间 | 30–32% | 28–33% | 9–10% |
| 明显偏在一侧（> 15 dB）的时间 | 30–44% | 31–38% | 37–43% |
| 每一侧连续停留 p25 / 中位 / p75（说话时间） | 0.8–1.1 / 1.6–2.8 / 2.7–5.7 s | 3.4–4.6 / 4.8–6.7 / 10.3–11.2 s | 3.6–4.0 / 3.9–4.3 / 4.9–5.1 s |
| 贴耳时近耳 30–70 Hz 相对 0.5–2 kHz | +7.5…+21 dB | −5.5…−12 dB | −15…−20 dB |
| 齿音帧 (5–12 kHz) − (0.5–2 kHz) 的 p90 / p99 | −7.5…+2.8 / +9…+20 dB | −4.3…+5.9 / +16…+22 dB | −0.1…+11 / +22…+28 dB |
| 说话响度的 p90 / p99（相对中位） | +7.8…+10.8 / +14.6…+19.7 dB | +9.6…+10.9 / +13.6…+16.0 dB | +7.7…+9.5 / +10.9…+14.3 dB |

剩下的差别：实录每一侧停留得更短，是因为真人在正面附近说话时两耳差本身就在 ±6 dB 上下晃，按这个口径会被数成很多次"换边"；贴得最近的那 10%（两耳差 28 dB 以上）本程序没有去追，贴得那么近时齿音和气流都更重。齿音剩下的差距是嗓音本身的（实录是轻语）。

每一项都可以单独再指定来覆盖。最初那两段实录的其他统计（两耳差起伏的标准差 5.5–5.8 dB、一个远近来回中位 4 s、退开时近耳音量保留 40–56%）是"忽远忽近"的标定依据，没有变。

可选的对比开关：
- `--dark 4`：贴耳时近耳 5 kHz 附近压低 4 dB，音色更"暗"（Koumura 等：频谱重心低于 1.5 kHz 的暗音色与 ASMR 相关；Terashima 2024：5 kHz 附近能量越低，刺痛感越强）。`--style ku100` 已经带 2 dB。
- `--room treated --wet -12`（Python 版）：加一点点房间声（Kopčo & Shinn-Cunningham：侧方声源的距离感靠两耳差，正前方的声源靠房间声）。
- Rust 版可从 `--style ear` 起步，加上 `--mode sweep --dist 0.15 --isolation 0 --far-lf-cut 0 --room real --headphone native`，复现第一版的设置。

### 呼吸音预设

`--style breath` 用于已经录到吸气、呼气和停顿的输入。参考均为 B 站提供的双声道 48 kHz、24 位 FLAC。每条录音在全片不同位置抽取 8 个 22 秒窗口，结合时频图、气流起伏和停顿选出候选段，再核查以下三口没有明显基频的侧耳呼吸。下表的双耳差为 100 Hz–6 kHz 左耳相对右耳的电平差，高频比为 3–6 kHz 相对 300 Hz–1 kHz 的功率比。整轨响度含录音中的其他声音。

| 无损参考 | 核查片段 | 双耳差 | 高频比 | 整轨响度 |
|---|---|---:|---:|---:|
| [枕边女友系列 · 绝赞呼吸音](https://www.bilibili.com/video/BV1ZndxYSE4Z) | 29:40.24–29:42.93 | −20.7 dB | −32.9 dB | −29.7 LUFS |
| [桥桥 ASMR · 抱着睡](https://www.bilibili.com/video/BV13SMXzuEMh) | 20:54.46–20:55.75 | +23.8 dB | −30.4 dB | −26.3 LUFS |
| [魔女姐姐的呼吸音](https://www.bilibili.com/video/BV1TkJU6qE9B) | 01:11.33–01:13.12 | −15.8 dB | −24.7 dB | −20.1 LUFS |

三条都保留了气流低频，高频较柔。第三条还有近乎居中的段落，所以这里选取侧耳段作为预设的空间目标。默认声源距头中心 15 cm，每侧从有声活动开始至少停留 5 秒，等到一次新的停顿后用约 0.8 秒经过脸前换边。关闭额外的高频气声提升，近耳采用 KU100 音色校正，5 kHz 处再收低，远耳保留实测房间反射。气流扑耳为 0.25 倍，使用原声送气包络产生 50–130 Hz 起伏。用户演绎的每口气和换气间隔决定输出节奏。

「呼吸去闷」比较 180 Hz 与 560 Hz 两个频带的平滑功率，以约 45 ms 跟踪一口气的音色。两带等功率时不衰减，低频带高出 6 dB 时达到设定的最大衰减。预设取 6 dB，归零可逐样本旁通。它在空间化和气流合成前处理原声，也可用于已经带有明显近讲低频的录音。

第一版预设的试听取第三条原始 FLAC 的 08:04.5–08:22.5，左右等权下混后使用默认呼吸音预设，导出响度与原片段同为 −24.2 LUFS。三口原本居中的呼吸经处理后双耳差分别为 +17.7、+17.4、+17.9 dB，高频比分别为 −33.7、−25.4、−29.2 dB。同一输入关闭和开启 6 dB 去闷，100–300 Hz 相对 300 Hz–1 kHz 的功率比在三口呼吸中分别下降 0.3、0.6、0.2 dB。这里验证的是侧耳位置和频带平衡，换一个话筒或换一个人呼吸时，原始口型与气流的差异仍会保留。

**薄声补偿与换气时换边**

对低频已经充足、含普通说话或其他声源的输入，补偿量需要随内容变化。「薄声补偿」每 16 ms 比较低频、中频、高频功率，用近期背景电平和中频波形的自相关判断是否有起伏的非周期声。只有低频不足时才加强从送气声提取的气流脉冲；3 kHz 以上相对突出的成分才会触发以 4.25 kHz 为中心的柔化。气流旋钮置零也会关闭补出的气流。呼吸预设的薄声补偿为 85%，其他预设默认关闭。

「换气时换边」使用穿梭模式的停留时间作为每侧最短停留时间。从这一侧出现活动声开始计时，到点后等待声音落下并确认短暂停顿再移动。持续发声时保持这一侧，连续静音也不会按计时器来回走。它使用实时可知的活动电平；若下一口很快开始，移动可能在起音后才完成。

一段 14.38 秒、左右声道相同的麦克风输入里，超过七成的 10 ms 窗低于 −100 dBFS。新旧预设均输出到 −26.0 LUFS。九个有声窗口的 25–100 Hz 相对 300 Hz–1 kHz 的功率比中位数从 −25.0 dB 变为 −6.4 dB。前五个窗口在左、后四个在右，在 6.77 秒原声静音时经过正中。输入中已经消失的气息仍是停顿。

另从上表三条参考分别保留 03:23、12:07 和 16:36 起的 12 秒片段，不用于选参数。各自等权下混，固定其他参数，把薄声补偿从关闭调至最大。三段低频相对中频的变化均在 0.08 dB 以内，3–6 kHz 的变化均在 0.31 dB 以内。在独立的 48 秒测试中，持续风扇和旋律段的频带变化均在 0.06 dB 以内，旋律、朗读、呼吸和风扇同时出现的片段在 0.09 dB 以内。朗读单独叠风扇时，25–100 Hz 相对中频增加 3.86 dB。部分无声辅音仍会触发气流补偿，普通说话为主的输入可降低「薄声补偿」或「气流扑耳」。

### 掏耳（入耳）`--style earclean`

给棉签、挖耳勺、刮擦这类"触发音"用的预设（只有 Rust 版有），不是给人声用的：声源贴在一只耳朵上并伸进耳道进进出出，另一只耳朵基本听不到，每只耳朵停留约 40 秒才换边。输入最好是"干"的摩擦 / 刮擦声（隔着一点空气录的，或对着话筒附近的东西刮）；人声放进来会变成"在耳道里说话"，没有意义。

按两段 KU100 掏耳实录标定（B 站，鬼花 malice 131 分钟、烛灵 40 分钟，棉签和挖耳勺；只提取统计特征，音频不会混入输出）。实录里量到的：

| 特征 | 两段 KU100 掏耳实录 |
|---|---|
| 哪只耳朵 | 一次只掏一只：一段是每只耳朵 5–20 分钟才换，另一段 1–2 分钟一换（两段都夹着几段两只耳朵同时掏）。另一只耳朵只剩底噪——底噪低的那段，500 Hz 以下比近耳低 37–46 dB；这是底噪决定的下限，穿过头壳传过去的声音比它还小 |
| 近耳的音色 | 非常"暗"、低频极重：1/3 倍频程电平相对 1 kHz，40 Hz +26…+27 dB、100 Hz +15…+21、250 Hz +11…+13、2 kHz −8…−10、5 kHz −14…−17 dB，8–12 kHz 又回升到 −4…−12 dB |
| 耳内低频 | 20–160 Hz 比 300–2000 Hz 的摩擦声高 10–20 dB（棉签 +10…+12，挖耳勺和另一段 +15…+20；整段平均 +16 / +20）。两者的包络同步：相关多数在 0.62–0.76，时差 0–20 ms。低频段内是粉红谱（25–160 Hz 各 1/3 倍频程相差 ±2 dB 以内）；挖耳勺每刮一下是一个约 35 Hz 的衰减振荡 |
| 进出 | 谱图上有一条随棉签进出来回滑动的共振峰：最外面约 3 kHz，最里面约 11 kHz，同时能看到它 3 倍频率上的第二条。峰比周围高 5–8 dB（中位），滑动速度中位每秒 0.4–1.1 个倍频程（最快的 10% 是 1.8–4.8），一个来回 2–6 秒，两头停得多、中间走得快 |
| 一下一下 | 每秒 0.9–2 下，每下中位 0.16–0.31 秒，有声音的时间占 49–63% |
| 深浅与响度 | 没有稳定的关系（共振频率与各频段电平的相关系数绝对值不超过 0.34） |
| 响度 | −18.3 和 −20.8 LUFS，峰值已经削顶（+1.6 / +2.2 dBTP） |

做法（都随"入耳程度"渐入，没伸进耳道时为 0；入耳深度为 0 时这一组全部不起作用，输出与加入这一组之前逐样本相同）：

| 做法 | 依据 | 参数（掏耳预设的值） |
|---|---|---|
| 入耳深度与进出：声源贴到耳朵上（离耳道口 0.75 cm 以内、正侧方）才伸得进去，按"在耳道口停一下 → 伸进去 → 在里面停一会儿 → 退出来"循环，时长和深浅带随机，偶尔只伸到一半、偶尔整个拿出来；按"有声音的时间"走，没声音时几乎不动。换边前 0.8 秒先退出来，到了另一只耳朵再从耳道口慢慢伸进去 | 上表"进出"一行。抚触类的刺激 1–10 cm/s 最舒服（Löken 等 2009；ASMR 视频里 9 cm/s 比 3 和 1 cm/s 更愉悦，Liu & Kondo 2025）：2 cm 的行程用 0.7–1.6 秒，约 1.3–3 cm/s。戴耳机听"刷子刷人工头耳朵"的录音时，"自己耳朵发痒"的评分约 4.9 / 7，从 80 cm 外的音箱放只有约 2.9（Kitagawa & Igarashi 2005） | `--inear 2.1`（cm，0 = 不进耳道）`--inear-period 4` `--inear-random 0.7` |
| 耳道共鸣：物体与话筒（鼓膜）之间剩下的那段耳道是一根一头堵住的短管，在四分之一波长的奇数倍频率上共振（c / 4L、3 倍、5 倍……）。用带负反馈的梳状滤波器实现：直流和偶数倍频率上增益为 1，共振峰高约等于设定值（反馈环里的插值在高频有一点损耗，设 10 dB 时实际是 7.5–10 dB，3 倍频率上的峰更矮）；时延逐样本变化，滑动时没有拉链声。等效长度按实录定：在耳道口 2.9 cm（约 3 kHz），最深处 0.8 cm（约 10.7 kHz）；进出的手势在"共振频率的对数"上是匀速的，和实录谱图上的 V 字形一致 | 上表"进出"一行（3 → 11 kHz，以及 3 倍频率上的第二条）。真人耳道约 25 × 8 mm，耳道口到鼓膜在 3–5.5 kHz 有约 14 dB 的增益（Hammershøi & Møller 1996）；堵住耳道口的 IEC 60318-4 耳模拟器（1.26 cm³）的共振在 13.5 kHz（GRAS RA0402）——腔体越短共振越高。KU100 的耳道比真人短得多（Neumann：约 6 mm 宽的短通道接着话筒），所以这里的"等效长度"是按实录量出来的，不是它的实际尺寸 | `--canal 10`（dB，0 = 关闭） |
| 耳内低频：取输入里 250 Hz 以上摩擦声的整流包络，留下它在 25–170 Hz 的起伏（每一下微小的黏滑 / 磕碰就是一个压力脉冲），整形成粉红谱，再按"慢包络 ÷ 快包络"的平方根做 2:1 压缩，让它像实录那样连续地隆隆响。只用输入自己的成分，不生成噪声；幅度与输入成正比，没有声音时为 0。加在直达声的输入上，只进伸进去的那只耳朵 | 上表"耳内低频"一行。堵住的耳道是"顺性控制"的小腔体，同样的壁面振动在里面形成的低频声压比敞开时高得多：模型给出约 −40 dB / 十倍频程、100 Hz 处 45 dB（Carillo 等 2020）；真人耳朵上实测的堵耳效应比模型小，而且塞得深比塞得浅再小约 15 dB（Stenfelt & Reinfeldt 2007 的数据，转引自前者）；入耳式话筒里，体内传来的声音在 1 kHz 以下最多被抬高 40 dB，事件的能量集中在 100 Hz 以下（Ma 等 2021）。手碰话筒的噪声也以低频为主（手持话筒在约 100 Hz 和 200–300 Hz 有共振，Kendrick 等 2015）。挖耳勺的 ASMR 在人工头上被描述为结构传声（Inanaga 2020）。刺痛感与 40 / 80 Hz 包络的强弱正相关（Terashima 等 2024）。揉搓声是密集的小冲击、刮擦声是稀疏的冲击（Conan 等 2013）——整流包络对两者都成立：密的变成连续的隆隆声，疏的变成一下一下的闷响 | `--rumble 1`（倍，0 = 关闭） |
| 入耳后不经过耳廓：近耳的响应从 HRIR 换成平直的（与贴在耳道口正外面一样响），不再随耳朵外面那一点位置的晃动变化；另一只耳朵再压低 30 dB | 声源已经在耳廓里面，耳廓的方向染色不再起作用。上表"哪只耳朵"一行。掏耳声是研究里两耳相关最低的 ASMR 触发音（IACC 0.02），锐度最低、粗糙度最高，在人发出的触发音里 ASMR 评分最高（Shimokura 2022） | 内置；`--isolation 40` |
| 堵耳闷感：伸进耳道时近耳 2.5 kHz 以上压低 | 物体把耳道口堵住了一部分。实录的近耳 5 kHz 比 1 kHz 低 14–17 dB；暗的音色（Koumura 等 2021）、5 kHz 以上包络低（Terashima 等 2024）都与刺痛感相关 | `--muffle 6`（dB，0 = 关闭） |
| 每只耳朵停留约 40 秒，换边 2 秒 | 实录是 1–20 分钟才换；研究里战栗感比声音滞后约 2 秒（Koumura 等 2021）。40 秒是为了几分钟的素材里两只耳朵都能轮到，想更久就调大停留时间 | `--hold-time 40` `--move-time 2` |
| 人声用的几项关掉：气声增强、气流扑耳、耳甲共鸣、贴耳轻声、嘴的大小、临场感、忽远忽近；自然晃动减小 | 这些都是按"嘴在耳边说话"做的 | `--breath 0 --puff 0 --concha 0 --soft-near 0 --mouth 0 --presence 0 --sway 0 --sway-follow 0 --micro 0.3` |
| 目标响度 −20 LUFS（实时 / 试听的自动响度 −23） | 上表"响度"一行。低频为主，K 加权的读数偏低而峰值很高；实时的自动响度按"有声音时的平均"拉，一下一下的声音会比目标高 3–5 LU，所以定得再低一些 | `--lufs -20` |

校验：把实录的近耳声道滤掉 250 Hz 以下（只剩摩擦声，相当于"隔着空气录的干声"）当输入，用掏耳预设处理，再和它自己原来的样子比；另外用一段合成的刮擦声（没有任何共振和低频）单独看共振：

| | 实录（4 段，各 1–2 分钟） | 本程序（同样的摩擦声） | 本程序（合成刮擦声） |
|---|---|---|---|
| 耳内低频比摩擦声高（20–160 Hz 对 300–2000 Hz） | +10.4…+20.3 dB | +14.5…+15.0 dB | +9.0 dB |
| 低频的峰度（越小越连续） | 4.8–8.1 | 8.3–12.9 | 11.2 |
| 1 kHz 以上的谱形与实录相差（1/3 倍频程） | — | 10 kHz 以下 ±2 dB，12.5–16 kHz 低 2–4 dB | — |
| 共振峰的位置 p10–p90 | 2.8–12.3 kHz | （输入里已经带着实录自己的共振） | 2.8–9.5 kHz |
| 共振峰比周围高（中位） | 5.3–6.8 dB | | 5.2 dB |
| 共振峰滑动速度（中位） | 0.4–1.1 倍频程 / 秒 | | 1.2 倍频程 / 秒 |
| 另一只耳朵 | 只有底噪 | 比近耳低 100 dB 以上 | 同左 |
| 响度，限制器 | −18.3 / −20.8 LUFS，削顶 | −20 LUFS，最多压 4–5.5 dB | −20 LUFS，3–4 dB |

要知道的局限：
- 耳内低频是由输入的包络导出的，不是真的测到的低频。输入本身低频就重（比如直接摩擦话筒录的）时两者会叠在一起，把"耳内低频"和"温暖感 / 近耳低频"调低。
- 干的摩擦声在 160–500 Hz 往往比实录薄：这一段靠"温暖感"（两耳共同的低频架）补，预设留在默认的 6 dB，输入很干时可以加到 9–12 dB。
- 挖耳勺那种每刮一下约 35 Hz 的闷响没有单独做，稀疏的刮擦声得到的是较宽的低频脉冲。
- 两只耳朵同时掏：单个输入做不到（两只耳朵放同一个声音会跑到脑袋中间），用"多音频合成"放两段不同的素材，一段在左耳、一段在右耳。
- 输入降噪（RNNoise）会把这类声音当噪声压掉，掏耳时关掉或调低。
- 低频要耳机放得出来：很多小耳塞 40 Hz 以下出不来，听到的主要是 50–160 Hz 那一段。

没有做成选项的：穿过头壳传到另一只耳朵的声音（实录里比底噪还小）、另一只耳朵的底噪（本程序不合成任何噪声）、深浅与响度的联动（实录里没有稳定的关系）、棉签 / 挖耳勺本身的摩擦声（要靠输入）。

| `--soft-voice 1` | 轻声化：按 ANSI S3.5 不同说话力度的标准频谱，把嗓音均衡到"压低声音说话"（中频略收、低频更饱满、最高频气声略多），只做均衡 | Brungart & Scott 2001（JASA）：说话声的距离感主要取决于说话力度，力度每增加 15 dB 听起来远一倍，播放音量几乎不影响；耳语 / 轻声听起来最近 |

`--style ku100` 默认就带 `--room real`。人为合成的底噪、吸气声、气音、气流声（用噪声合成的那几种）听起来不真实，已从程序中删除；现在的 `--breath` / `--puff` 是另一回事，只用嗓音自己的气声，见上面"贴耳气声与耳甲共鸣"。

数据来源：`data/room_audiolab_ku100.npz` 提取自 Lübeck, Arend, Pörschmann (2021) "A High-Resolution Spatial Room Impulse Response Database"（[Zenodo 5031335](https://zenodo.org/records/5031335)，BRIR_Audiolab_LSC_KU100_P1，CC BY 4.0），去掉了直达声并缩短了混响时间。

## 背景音：雨声（`--bg rain-night`）

只有 Rust 版有（安卓版、浏览器插件用的是同一份代码）。背景音是可选的：音量为 0 时完全不参与，输出逐字节不变；人声本身一点不动。雨声不用录音素材，全部按雨滴落地的物理过程实时生成，每一滴都按 KU100 HRTF 摆在它自己的方向上；实时（主播）、试听和文件转换用的是同一套代码。用法见[界面使用说明 · 背景音](app-usage.md#背景音雨声)。

现在是第二版：第一版的窗玻璃雨点和水泡声试听下来"像手指敲玻璃，吵死了""水泡声特别明显、有点恶心"，于是照一段 8D 环绕雨声改了，见下面"第二版：照 8D 环绕雨声改"。

### 做法和依据

| 部分 | 做法 | 依据 |
|---|---|---|
| 雨滴 | 雨量 R（mm/h）下直径按 Marshall–Palmer 谱 N(D) = 8000·e^(−ΛD) /m³/mm，Λ = 4.1·R^−0.21 /mm；下落速度 v(D) = 9.65 − 10.3·e^(−0.6D) m/s。雨越大，大雨滴越多 | Marshall & Palmer 1948；Atlas、Srivastava & Sekhon 1973 |
| 一滴打在地上 | 一个很短的压力脉冲：开头几微秒的尖峰（水锤），再跟一个宽度等于接触时间 D/v（0.26–0.64 ms）的单周期正弦；峰值 ∝ D·v³ / 距离——大雨滴更响、更低沉。40% 落在软的表面上（树叶、草、泥土），接触时间长 2.5 倍，还带一个单极的"噗"（表面被压下去、挤开空气），声音更低。尖峰大小、软表面的比例和宽度、单极成分是对着真实录音拟合的（见下面"和真实录音对照校准"） | Miklavcic、Zita、Arvidsson 2004（DAFx）：撞击声是解析的短脉冲，强度和雨滴的动能、落点的距离有关；Metcalf 等（hardRain）：热带雨林录音里雨打植物在 0.6–1.2 kHz 和 4.4–5.6 kHz 最明显 |
| 整片雨声 | 雨滴均匀落在以听者为中心的三个圆环里（近 0.5–3 m、中 3–12 m、远 12–50 m，耳朵离地 1.2 m），每一滴从它自己的方向（KU100 HRIR，含仰角）、按 1/距离 衰减地到达两耳，两耳之间的相关、远近的明暗都是叠加出来的。远处两个圆环有遮挡（功率 ×0.7、×0.35）；三个圆环按距离低通（10、8、6 kHz，对着录音拟合）。每个圆环每秒只逐个渲染最大的两三千滴，更小的合成能量相同、正负号随机的稀疏脉冲 | DAFx 2004 的做法：落点在两个圆之间的圆环里随机，安排的是"到达时间"而不是"撞击时间"（否则开头会有个渐强）；Välimäki 等 2013：稀疏的 ±1 脉冲（velvet noise）每秒两千个以上听起来就是平滑的噪声 |
| 为什么不用滤波白噪声 | 雨这类纹理靠零星而集中的事件（稀疏）和各频带同步起伏才像 | McDermott & Simoncelli 2011（Neuron）：只把各频带的功率做对（相当于同频谱的噪声）时，听的人基本认不出是什么纹理；加上包络的方差 / 偏度 / 峰度和频带之间的相关才自然 |
| 雨量起伏 | 雨量以十几秒的节奏轻轻起伏（对数正态 ±25%，时间常数 14 s） | 真实的雨不是一成不变的 |
| 流动（8D 环绕） | 雨点落在哪个方向不是一直均匀的：有一个"重心"绕着头转，平均 26 秒一圈（转速按时间常数 20 s 随机慢慢变，对数标准差 0.45），重心那边落得密——方向 θ 上的密度 ∝ e^{κ·cos(θ − 重心)}，κ = 2 ×（流动/100）²。整片雨声和落地声都跟着它；在"左右""包围感"划定的范围里起作用 | 参考的 8D 环绕雨声：1–4 kHz 的左右差（每 0.5 s）标准差 1.6 dB，自相关 4 s 降到一半，起伏的主周期约 26 s 和 52 s。流动 50 时我们是 1.5 dB、5 s、24–46 s |
| 落地声 | 身边 0.7–3 m 的地上（泥地、草、积水）一个个听得出的雨点：一团低沉的"噗"——白噪声乘包络（4 ms 起音，时间常数 35–60 ms 衰减）过带通（中心 170–300 Hz，Q 1）、700 Hz 二阶低通、160 Hz 四阶高通，开头带一点点溅水的"沙"（1.5–5 kHz、3 ms，能量低约 25 dB）。按落点卷对应方向和仰角的 KU100 HRIR；远近按 1/(r² + 1.2²)，轻重再有对数正态 σ 0.3 的不同。每秒 1–5 个（随雨量）。滑块 60 时和参考一样明显，每格 0.2 dB，默认 30（低 6 dB）。是噪声，没有音调 | 参考里的落地声：250 Hz 倍频程比背景高 7.5 dB、500 Hz 高 4 dB、1 kHz 以上几乎不变，约 80 ms 后听不出来；每秒约 0.8 个比背景高 8 dB 以上，峰值中位 9 dB |
| 屋檐滴水 | 1–3 处固定的位置，各有各的节奏（每滴 ±10% 随机，再慢慢漂移 ±20%）；落在石阶 / 积水的地上，"嗒"——一下 0.3–0.5 ms 的撞击、一小团溅开的水（各处中心频率不同，1.2–3.6 kHz 的带通噪声，4–8 ms）和一点点 250–400 Hz 的"噗"；没有气泡，没有音调。响度跟着落地声（比一个落地声高 2 dB），落地声为 0 时没有 | 第一版是落进水洼的气泡声（音调上滑 ξ 0.25–0.55，Zheng & James 2009），听着恶心，改掉 |
| 隔窗 | 外面的雨（连同落地声）按墙和玻璃的隔声：一阶低通（每倍频程 6 dB，拐点随滑条从 20 kHz 降到 900 Hz），125 Hz 附近的共振透得多一点（最多 +14 dB），再漏 2% 进来；屋檐滴水闷一半 | 质量定律：隔声量随频率升高，每倍频程约多 6 dB；双层玻璃 / 墙体在一两百赫兹有"质量-空气-质量"共振。具体数值对着关着窗的夜雨录音校过 |
| 响度 | 增益按期望功率解析地算：每种雨滴的频谱 × 方向分布下的 HRIR 功率谱 × 各级滤波 × 回放补偿 × K 加权，求和；让整片雨声的积分响度 = 人声的目标响度 + 音量（dB）+ 雨量带来的 ±5 dB。落地声、滴水按整片雨声的功率定响度 | ITU-R BS.1770 |

### 实测

- **响度**：只有整片雨声时（测试里去掉了雨量起伏），毛毛雨 / 中雨 / 大雨 / 暴雨、在外面 / 隔窗 / 偏向一侧这 4 种设置下，40 秒的积分响度和设定值相差 0.8 dB 以内；带着雨量起伏时，120 秒的实测在设定值上下约 1 dB。
- **频谱**：见下面"和真实录音对照校准"。在外面、雨量 35（各倍频程相对总能量）：125 Hz −15、250 Hz −12、500 Hz −9、1 kHz −6、2 kHz −6、4 kHz −8、8 kHz −14、16 kHz −21 dB。
- **稀疏程度**（2–4 kHz 包络的峰度；高斯噪声约 3.2，越大越"一滴一滴"）：只有整片雨声时，毛毛雨（雨量 10）26、中雨（35）6.3、暴雨（90）4.4——雨越大越密。
- **两耳**：四周都有时两耳几乎不相关（相关系数小于 0.1）、左右一样响；只从正前方来时相关大于 0.6；全在左边时左耳响 6 dB 以上。隔窗 100 时 4 kHz 以上的能量占比比在外面少 13 dB（录音：屋里约 −18 dB，室外平均约 −8 dB）。
- **没有突出的一下**：雨夜（第二版）每 10 ms 一帧和 1 秒滑动中位数比，全频 99.9% 分位 5 dB、最大 8 dB；第一版是 24.5 dB、26 dB（每秒两三下比雨声高 15 dB 以上）。测试里查着：雨夜全频 99.9% 分位 < 8 dB、最大 < 11 dB。
- **放进人声里**：同一段 60 秒的人声转换，不加雨时限制器最多压 4.3 dB；加第二版雨夜还是 4.3 dB（第一版雨夜是 6.4 dB：窗玻璃上的雨点碰上人声的峰值）。
- **CPU**：生成 60 秒雨夜用约 0.4 秒；`auto-asmr bench` 模拟实时回调（每块 128 个样本，2.67 ms）：贴耳加强单核约 1.5%、加雨夜约 1.9%，最慢的一块从 132 µs 到 288 µs（落地声那一下的 HRTF 卷积）；落地声、滴水、雨量全拉满约 2.0%、最慢 304 µs。
- **还没做的**：没有风声；雷声没有对照的录音（见下面"雷声"）；屋檐滴水没有对照的录音；两耳相关只和双耳录音比过（另外几段是普通立体声或单声道录音）；参考的 8D 雨声有约 22 分钟一轮的强弱起伏（中间响 4 dB 左右），我们只有十几秒的小起伏。

发现和改动：

- **真实雨声的样子差别很大**，主要看离雨点多近、打在什么上：远处 / 开窗听到的偏闷（4 kHz 以上很快掉下去），雨打近处树叶的很亮、很稀疏，大雨又亮又密。所以"在外面"按 4 段室外录音的平均校，"隔窗"按 2 段屋里录音的平均校，稀疏还是密交给"雨量"和"近处雨滴"两个滑条。
- **第一版高频太多、低频太少**：4–16 kHz 比录音的平均多 7–9 dB（双耳录音本来还带着耳廓在 2–5 kHz 的增益，就这样也比我们暗），125–250 Hz 少 5–12 dB。用一个快速的频谱模型（雨滴谱 × 脉冲谱 × 圆环低通）对着 4 段室外录音的平均拟合撞击脉冲的参数：撞击尖峰取大（硬表面 3.0、软表面 1.5，开头更利落），三个圆环的低通收到 10、8、6 kHz，软表面 40%、接触时间长 2.5 倍并加上单极的"噗"。拟合残差 0.8 dB；实际渲染（含 HRIR 和回放补偿）在雨量 35 时，250 Hz–8 kHz 每个倍频程和录音平均相差 1.8 dB 以内，125 Hz 少 2.6 dB（录音里这一档有风和远处的低频）。纹理也落在录音的范围里：包络的归一化方差 0.09–0.32（录音里稳定的雨 0.06–0.42）、峰度 4–15、400 ms 的响度起伏 0.6–0.8 dB（录音 0.8–3.4 dB）。
- **隔窗**（第二版又改过，见下面）：原来的二阶低通做不出屋里录音的形状（125 Hz 有个峰、250 Hz–2 kHz 很平、2 kHz 以上滚降），改成质量定律的一阶低通 + 125 Hz 的共振峰。屋里录音里玻璃上的雨点很突出（响度起伏 3.7–5.2 dB、频带之间的相关 0.5–0.67、每秒 3–4 个"突出的一下"），原来的雨点太弱（起伏 1.1 dB、相关 0.11）：给窗玻璃加上整块玻璃的低模态、让"嗒"更宽频、把 2 kHz 那一簇调轻，隔窗时窗玻璃和窗台上的雨点再响 8 dB；去掉了窗台的金属"叮"（长长的 2.5–7.5 kHz 尾音录音里没有，调响以后 8 kHz 会多 5–7 dB）。结果：隔窗 100、近处雨滴 30 时，125 Hz–4 kHz 每个倍频程和屋里录音的平均相差 2.6 dB 以内（8 kHz 少 4 dB），响度起伏 3.4 dB、每秒 4 个"突出的一下"，频带之间的相关 0.32（录音 0.5–0.67，还偏低）。
- **雨夜预设**改成隔窗 90、包围感 60（屋里听，雨主要从窗户那边来）；原来是隔窗 60、包围感 100，和"关着窗"的说法不一致。（第二版又改回四面八方、不隔窗。）
- 测试里加了一条：在外面和隔窗两种设置下，250 Hz–4 kHz 每个倍频程要在录音的 ±3 dB 以内，以后改参数偏离真实录音时会报出来。

### 第二版：照 8D 环绕雨声改（2026-11-20）

**为什么改**：第一版的雨夜试听下来，窗玻璃上的雨点"像手指敲玻璃，吵死了"，水泡声（屋檐滴水和水洼里的"叮"）"特别明显，有点恶心"。用同一段雨夜量出来：每秒约 3 下比雨声高 15 dB 以上，最响的一下高 26–38 dB——一是窗玻璃那几个 175–475 Hz 的低模态（敲出来就是指节敲玻璃的"咚"）再加隔窗时的 +8 dB，二是滴水做成了音调往上滑的气泡（1.2–3.6 kHz，比雨声高 20–30 dB）。真实的屋里听雨录音里，最突出的一下也只高 12–14 dB。之后指定照一段 8D 环绕雨声做，"水落地的声音不要那么明显，默认小一点，可以调节"。

**参考**：B 站 [BV1rE411P7ct](https://www.bilibili.com/video/BV1rE411P7ct/)《8D全景声音环绕，432hz更舒缓更助眠雨声-白噪音》，44 分 46 秒。简介说是用几百个雨声样本、按 HRTF 摆位置合成的虚拟环境声，强度和焦点随时间变化。只下了音轨（AAC 132 kbps，`音频/rain_ref/ref8d_rain_BV1rE411P7ct.m4a`，git 不跟踪），只用来测统计量，不混进任何输出。量出来：

|---|---|---|---|
| 倍频程（125 Hz … 8 kHz，相对总能量，dB） | −17.6 −10.5 −9.3 −5.2 −6.2 −8.1 −11.5 | 屋里的闷声，4 kHz 以上很快掉下去 | −15.1 −11.4 −8.5 −5.6 −5.7 −8.1 −13.9 |
| 两耳相关（500 Hz 以上） | 约 0 | — | 约 0 |
| 1–4 kHz 左右差的起伏（标准差） | 1.6 dB，自相关 4 s 降到一半，主周期约 26、52 s | 0.3 dB（在外面、四周均匀时量的；几乎不动） | 1.5 dB，5 s，24–46 s |
| 全频：10 ms 一帧比 1 秒中位数高，99.9% 分位 / 最大 | 6.7–8.5 / 7.6–10.4 dB | 24.5 / 26.4 dB | 5.0 / 8.2 dB |
| 150–500 Hz（落地声）：99.9% 分位，每秒超过 6 dB 的次数 | 11–12 dB，2.3–3.1 次 | 23 dB，2.5 次（"咚"） | 8.8 dB，0.8 次（落地声 30） |
| 1–4 kHz：99.9% 分位 | 7–8.7 dB | 32 dB（"叮"、水泡） | 5.6 dB |

**改了什么**：

- 去掉窗玻璃 / 窗台上的雨点、水洼里的"叮"、滴水的气泡——不再有任何带音调的水声。
- 加"落地声"：参考里比较明显的就是 150–500 Hz 一团团的"噗"（250 Hz 倍频程高 7.5 dB、500 Hz 高 4 dB、1 kHz 以上几乎不变、约 80 ms），照着它做（见上表"落地声"一行）。对着参考校：落地声 60 时每秒约 1.3 个比背景高 8 dB 以上（参考 0.7–1.0）、峰值中位 9.8 dB（参考 9.3）、事件的频谱 125 Hz … 8 kHz 比背景高 +3.2 +7.6 +5.7 +0.9 +0.2 0 +0.1 dB（参考 +2.8 +7.5 +4.1 +1.0 +0.5 +0.2 +0.2）、长约 70 ms；默认 30 低 6 dB，比背景高 8 dB 以上的每秒只剩约 0.1 个。
- 加"流动"：参考的左右差一直在慢慢摆（±2–4 dB），我们原来几乎不动，于是让雨点密度的重心绕着头转（见上表"流动"一行），流动 50 和参考一样。
- 屋檐滴水改成落在石阶 / 积水地上的"嗒"（噪声，没有音调），响度跟着落地声：默认（落地声 30）每一下在 1–4 kHz 比背景高约 4–10 dB（第一版高 28–38 dB）。
- 雨夜预设改成参考那样：四面八方（包围感 100）、流动 50、不隔窗、落地声 30、没有屋檐滴水（参考里没有）；雨量和音量不变。
- 隔窗的拐点从 700 Hz 改到 900 Hz：窗玻璃的雨点去掉以后，关窗时 2–4 kHz 比关着窗的夜雨录音少 3 dB 多，现在 125 Hz–4 kHz 都在 ±3 dB 以内。频谱测试里屋里那一档改成只和这段录音比（贴着玻璃录的那段是密密的雨打玻璃，不再是目标）。
- 落地声、滴水、流动各用各的随机数：调一个滑块不会把别的层的落点和时机打乱。
- 测试里加了两条：雨夜里没有突出的一下（全频 99.9% 分位 < 8 dB、最大 < 11 dB），落地声 30 / 60 / 100 的 150–500 Hz 99.9% 分位依次变大、60 落在参考附近；流动 0 / 50 / 100 的左右差标准差（< 0.7、1.0–2.3、> 3 dB）。
- 背景音关着时，转换结果和改之前逐字节相同（默认风格和 KU100 风格都对比过）。

### 雷声（可选，默认关）

"雷声"滑块 0 = 没有（默认，雨夜预设也不带雷）。和雨一样不用录音，按闪电的物理过程现算，走雨声的同一条路（同一个增益、隔窗一起闷掉、回放补偿；高通用 30 Hz 而不是雨声的 60 Hz，雷的隆隆声在 60 Hz 以下还有不少）。代码在 `src/dsp/thunder.rs`。

| 部分 | 做法 | 依据 |
|---|---|---|
| 闪电通道 | 曲折的随机游走：每段 8–25 m，段与段之间转 \|N(0, 20°)\| 的角（平均约 16°），绕一个随机的、垂直于当前方向的轴转。云地闪（45%）：从云底（1.8–3 km）往下走到地面，再在云里水平走 2–5 km，主干上半段长出 2–5 根 0.2–1.5 km 的分叉；云内闪（55%）：在 4–6.5 km 高处水平走 4–9 km | Hill 1968：闪电通道相邻小段之间的夹角平均约 16° |
| 一段发出的声音 | 放电把通道瞬间加热，激波衰减成一个 N 形的压力波，宽 6–14 ms（每次闪电取一个值；N 波的频谱峰在 0.66/宽度，约 50–110 Hz）。一段直的通道从侧面看是同时到达的一声"啪"，斜着看被拖开 L·\|cos ψ\|/c。通道在米的尺度上也是弯的，所以每 2 m 算一颗"珠子"，在拖开的时间里随机排开：低频合起来就是拖开的平均，高频不互相抵消。幅度 ∝ 段长 / 距离 | Few 1969（激波衰减成 N 波，"string of pearls"）；Ribner & Roy 1982（"炸"和"滚"都来自通道的曲折，斜着的段把 N 波拖开） |
| 多次回击 | 云地闪再来 1–3 次回击，间隔 40–120 ms，一次比一次弱（×0.4–0.7），只走主干 | 负极性云地闪平均 3–5 次回击 |
| 传播 | 每一段按距离 / 343 m/s 到达：近的先到、远的后到，一次闪电滚 5–15 秒。空气吸收：二阶低通，拐点 1000·(0.6/距离 km)^(2/3) Hz（1 km 约 710 Hz、3 km 约 340 Hz、8 km 约 180 Hz）。第一声的时间对齐到"打雷"的时刻（没有闪光，所以不等那 10 来秒的声速延迟） | ISO 9613-1 的大气吸收量级（20 °C、70% 湿度：1 kHz 约 5 dB/km、4 kHz 约 23 dB/km） |
| 方向 | 每一段从它自己的方向来：KU100 HRIR，方位每 5°，仰角 0°、15°…75° 六档——先从低处响起，再滚到头顶上、滚到远处。闪电落在哪个方位按雨声的"左右""包围感"抽 | |
| 回声 | 地形、建筑、云底的回声：4 路反馈延时网络（51–110 ms，Householder 反馈，每路一阶低通 700 Hz，混响时间 3 s），两耳的回声不相关，和直达声 1 : 0.5 相加 | Fineberg 等 2022 的听感测试：合成雷声里缺少回声、包络太规整是最常被指出的不像 |
| 多少、远近、响度 | 滑块越大越近、越频繁、越响：1 ≈ 平均 4 分钟一次、8 km 外；30 ≈ 2 分钟、4.8 km；50 ≈ 77 秒、3.5 km；100 ≈ 25 秒、1.5 km（中间按对数插；每次的距离再随机 ±40%，限在 0.8–15 km，不会有吓人的炸雷）。两次之间至少 8 秒，拉上来以后 3–10 秒内来第一声。每次闪电的总能量按 1/距离² 定：3 km 时 = 整片雨声 1 秒的能量再高 22 dB，再随机 ±2.5 dB | |

为什么不直接用纯信号的做法：Reiss、Tez、Selfridge 2021 比较了 9 种合成雷声，信号模型（滤波噪声 + 包络，Farnell 2010 一类）比物理模型（Ribner & Roy 那类）听着稍像一点，但都远不如录音；Fineberg、Walters、Reiss 2022 在 Farnell 的结构上加了"隆隆"、低频"咆哮"、回声和 HRTF 摆位，听感测试 54 人：录音中位 8.2 分、他们的 6.2、Farnell 5.0、纯物理模型 5.0；最常被说不像的是"太完美"（包络太规整）、开头像爆炸、回声不对。所以这里结构用物理的（到达的先后、方向、空气吸收都是算出来的，每次都不一样），再加多次回击和回声；没有用会带音高的窄带滤波。

实测（雨夜 + 雷声，每档 300 秒，同一个种子"有雷 − 没雷"拆出雷这一层）：

- **多少**：雷声 30 / 50 / 100 时 300 秒里打了 3 / 4 / 12 次（设计的平均间隔 122 / 77 / 25 秒）。
- **频谱**（倍频程 31.5 Hz…4 kHz，相对最大一档）：雷声 100 时 −5.4、0（63 Hz）、−2.2、−10.7、−19.3、−31.2、−45.8、−59.3 dB——低沉的隆隆声，1 kHz 以上几乎没有；距离越远越闷。测试里查着：250 Hz 以下占八成以上、1 kHz 以上不到 1%。
- **响度**（K 加权、3 秒，相对雨声）：雷声 30 最响的一声 −4 dB（在 40–200 Hz 里比雨声高得多，听得到低沉的闷雷）；50 是 −9 … 0 dB；100 是 −1 … +9 dB，雨加雷合起来最响比平时高 9 dB。
- **会滚**：一声雷在它峰值 −20 dB 以内持续 5–10 秒。
- **放进人声里**：同一段 60 秒人声 + 雨夜，加雷声 50 或 100，限制器最多压的量都还是 4.3 dB（和不加雷一样）。
- **不打雷时不变**：雷声 0 时，纯雨声、隔窗 / 大雨 / 流动、人声 + 雨夜、背景音关这几种输出和加雷声之前逐字节相同；打开雷声时，第一声雷之前也逐样本相同（雷用自己的随机数）。
- **CPU**：`auto-asmr bench` 里雨夜 + 雷声 100 单核约 2.0%（不带雷 1.8%），最慢的一块 266 µs；每个控制块最多渲染 2 段通道，多出来的推到下一块（晚一两毫秒），免得一块里算太多。
- **还没做的**：没有和真实雷声录音对照过频谱、长短和响度（文献里雷声的频谱峰在 50–250 Hz，这里是 63 Hz 那一档）。

## 和参考视频（BV1KPJDzHEVV）的区别

分析原视频音频发现，它的双耳时间差（ITD）全为 0，各频段的双耳声级差（ILD）也完全一样。也就是说，它只是左右**音量声像**，在"左→中→右"之间来回切，经常把一侧直接关到 −60 dB。这样听起来像声音在耳机里面，而不是有人在耳边。

本程序按真实声学来做：

| | 原视频 | 本程序 |
|---|---|---|
| 双耳时间差 ITD | 0 | 0–0.85 ms，随位置连续变化 |
| 头影 / 耳廓滤波 | 无（各频段 ILD 相同） | Neumann KU100 人工头实测 HRIR（很多 ASMR 用的就是这个人头） |
| 距离感 | 只有音量 | 0.25–1.5 m 实测近场数据，0.095–0.25 m 用球头模型外推并做声学视差；近处低频 ILD 更大、更干，远处房间声更多 |
| 运动 | 固定 3 秒周期的自动声像：每只耳朵停 1 秒，0.5 秒穿过中间 | 默认 2.5 秒经脸前慢慢移到另一只耳朵，在耳边忽远忽近，带多普勒和人体自然晃动；`pingpong` 可复刻原视频的 3 秒节奏 |
| 空间 | 无 | 卧室早期反射（跟随声源方向）+ 双耳去相关混响 |

在 `音频/asmr_ref/demo/` 里有同一段内容的 A/B 对比（A = 原视频，B = 本程序处理，响度已基本对齐）。
