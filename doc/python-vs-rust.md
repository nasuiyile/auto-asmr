# Python 版与 Rust 版的关系

同一套算法，逐项对照过：

- **固定轨迹下逐样本一致**：贴耳、6 cm + 房间、绕头 12 cm、绕头 20 cm + 房间、正前 0.5 m 五种情况，再加六种带高度的（贴耳向上 40°、6 cm 向下 30° + 房间、绕头时向上 35° / 60°、正前向上 45°、头顶正上方），Rust 与 Python 输出的相关系数都是 1.00000，残差 −63 到 −72 dB。
- **上下全关时与加入上下功能之前逐位相同**：高度 0、自动上下 0、从头顶绕 0 时，五种设置下输出文件逐字节一致。
- **随机走位的统计一致**（两边随机数不同，比的是整段 10.5 分钟的分布）：在侧边的时间 72% 对 72%，贴耳时离耳中位 3.0 cm 对 2.5 cm，换耳 66 次对 62 次，限制器最多压 5.5 dB 对 5.5 dB。

Rust 版多出来的：实时模式（含"话少时也一直在动"）、试听、输入降噪、自动响度、随机走位模式（含正面比例 `--front`）、忽远忽近的随机程度、多音频合成、掏耳预设 `--style earclean`（入耳深度、耳道共鸣、耳内低频、堵耳闷感，见[效果与依据 · 掏耳](effects.md#掏耳入耳--style-earclean)）、呼吸音预设 `--style breath`（见[效果与依据 · 呼吸音预设](effects.md#呼吸音预设)）。

两版的 `--style ku100` 采用不同的标定。Rust 版用随机走位，并能用 `--breath-reach` 控制说话人从耳侧移到身前时保留的气声细节。Python 版沿用最初的左右穿梭、离耳约 6 cm 的设置。两版默认的贴耳加强风格都只在耳侧提升气声。各代 KU100 预设的参数见[效果与依据](effects.md#ku100-实录风格---style-ku100)。

Rust 版的「固定原声底噪」在实时和文件模式、安卓与 Chromium 上使用同一套分离器。Python 脚本仍把整个输入声道送入移动声源。

Rust 版没有移植的：合成房间（treated / bedroom / living）、爆破音气团、`phrase` / `pingpong` / `wander` / `path` 运动模式。需要这些请用 Python 版。
